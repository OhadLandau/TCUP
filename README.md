# TCUP – Tissue‑of‑Origin Prediction for Cancer of Unknown Primary (CUP)

**TCUP** is an open‑access web‑application and model suite that predicts the most likely tissue of origin for:

* cancers of unknown primary (CUP)  
* any transcriptomic sample (e.g. TCGA, GTEx, metastatic, healthy)

The method couples a **Contrastive Auto‑Encoder (CAE)** for representation learning with a **Siamese Neural Network (SNN)** meta‑learner trained on curated TCGA, GTEx and metastatic cohorts. The embedding generated by both models are then fed to 5 base classifiers which are fine-tuned to elicit the best prediction through a Meta Learner (MLP).   For full methodology see the pre‑print:

> Landau O., Rubin E. “TCUP - An Open Access Tool to Predict Tissue of Origin for Cancer of Unknown Primary (CUP)” (in preparation, 2025).

# Update-  **TCUP v2 update notes**

**Data & Normalization:**

- All three sources are now in the same unit: TPM computed with one formula and the same gene lengths from raw counts (GTEx gene reads, TCGA RSEM counts, metastatic RSEM expected counts), then log2(TPM+1)
- Only discordant metastases are kept (samples whose biopsy site equals the primary site are removed); metastatic classes with fewer than 5 samples are removed
- KNN imputation is fitted on training samples only, and every sample is brought back to a total of 1,000,000 TPM after imputation

**Splits & Leakage:**

- GTEx and TCGA are split 60:20:20, stratified by label and grouped by donor (GTEx) or patient (TCGA), so no donor or patient appears in two splits
- The metastatic held-out test set is unchanged in size (20 LUAD, 25 PAAD, 40 BRCA, 35 COAD); the remaining metastatic samples are split 75:25 into train and validation
- Leakage checks on sample ID, donor/patient ID and identical expression profiles, before and after scaling and SMOTE

**Gene Selection:**

- New gene list of 1,576 genes: one-vs-rest LASSO on real training samples only (no validation, test or synthetic samples), using the strictest penalty that keeps at least 1,500 genes
- StandardScaler fitted on training samples; SMOTE applied per metastatic class on training samples only

**Models:**

- SNN and CAE architectures, losses and epochs are unchanged. Positive metastatic pairs now require the same tissue label, and negative partners are drawn at random
- Base classifiers are tuned once with GridSearchCV on base-training data, and the out-of-fold meta-features use the tuned settings
- Base classifiers are trained on the training split plus 70% of the validation split; the meta-learner architecture is chosen on the remaining 30% of validation, which the embedders and base classifiers never saw. The test set is scored once, with the chosen model
- Results are reported over the 45 classes that have test samples. HNSC, SKCM, STAD and UCEC metastases have training samples only and are not given as predictions

**Model Interpretation:**

- Monte Carlo gene ablation (noise σ = 20, 10 cycles) on the held-out test set. A gene is significant when its accuracy drop stands out against all other genes (robust z-score), after Benjamini-Hochberg correction (FDR < 0.05)

**Web Application:**

- New interface: several samples per upload, a probability bar plot, and the 20 most influential genes for the predicted class with GeneCards and PubMed links
- `ExampleTranscriptomics.csv` now holds 9 held-out test samples in TPM: 6 the model gets right and one wrong from each source (GTEx, TCGA, metastatic)

**Performance (5 seeds, held-out test set):**

- Overall 98.56 ± 0.13%, GTEx 99.28 ± 0.10%, TCGA 98.76 ± 0.22%, metastatic 77.67 ± 3.82%
- Deployed model (seed 42): overall 98.57%, metastatic 82.50%

Full v2 script and the standalone Monte Carlo script can be found in the Script directory. The deployed model is the seed-42 v2 model.

# Update-  **TCUP v1.5 update notes**

**Meta-Learning Pipeline Improvements**:

- Implemented nested 64-16-20 split strategy (merged original 60% train + 20% val → 80% development set, then re-split into 80-20 splits for base classifiers(64% base-train and 16% meta-validation).
- Added GridSearchCV hyperparameter tuning for all base classifiers (4 hyperparameters per classifier, 5-fold cross-validation)
- Implemented cross-validation-based meta-feature generation (5-fold CV on 64% base-train produces out-of-fold predictions)
- Final meta-learner retrained on 64% base-train (using CV-generated meta-features) with 16% meta-validation monitoring before final test evaluation

**Data Quality & Reproducibility:**

- Added comprehensive duplicate removal (genes and samples) across all datasets before preprocessing
- Implemented donor-aware splitting for GTEx data to prevent sample leakage from same donors across train/val/test splits
- Enhanced data integrity unit tests covering SAMPLE_ID leakage, DONOR_ID leakage, duplicate detection, NaN/Inf checks, and label encoder consistency
- Added deterministic operations with fixed random seed (SEED=42) across all libraries including TensorFlow GPU operations
- Moved SMOTE application to after feature selection and standardization to prevent synthetic-from-synthetic data generation and ensure SMOTE operates on final feature space
- Added adaptive k_neighbors for SMOTE based on class sizes to handle small metastatic classes (min 1, max 5 neighbors)
  
**Documentation & Transparency:**

- Added detailed logging and checkpointing system for all preprocessing and training stages
- Generated comprehensive CSV reports tracking label counts, SMOTE operations, and split distributions
- Improved error handling with informative messages and automatic checkpoint recovery

**Performance:**

- Results: Similar to original with mild improvements in accuracy metrics
- All improvements validated on held-out 20% test set

## 🚀 Quick start

```bash
# 1. clone repo
git clone https://github.com/OhadLandau/TCUP.git
cd TCUP

# 2. install deps
python -m venv venv && source venv/bin/activate  # optional

# 3. launch the web server
```

## 🖼  UI tour

| Landing | Results |
|---------|---------|
| ![Landing page](images/LandingPage.png) | ![Results page](images/ResultsPage.png) |

* **Landing page** – drag‑and‑drop a CSV/TSV of **TPM** values where the **first column is `sample_id`** and the rest are *HGNC gene symbols* (genes as rows also work). Several samples can be uploaded at once. Choose **Cancer** vs **Healthy** to select the assumed tissue type, this will add missing genes and compute the Over/Under expression of most significant genes in predicting the predicted label in your sample (from models intepertation stage - see paper) against the closest assumed reference data.  
* **Results page** – shows:  
  1. 45 class probabilities (barplot), top to bottom.  
  2. Predicted tissue + model‑confidence (bold) - Probabilities and Models accuracy for that label on the test set.  
  3. **TCUP accuracy** – historical accuracy for that tissue on an unseen test set (≈ accuracy for the given label).  
  4. The 20 most influential genes in the decision (σ from the reference median; significant genes marked), with GeneCards and PubMed links.

## 📈 Interpreting the output

* **Predicted tissue** – the label (e.g. `SKCM_TCGA`) with the highest posterior probability.  
* **Probability** – the softmax score from the meta learner (0‑1).  
* **TCUP accuracy** – *held‑out* test‑set accuracy **for that tissue** only.  
  *Example*: “TCUP accuracy ≈ 96.7 %” means that, across the unseen test set melanoma (SKCM) samples were 96.7 %  correctly classified by TCUP.

If your sample’s probability is low (<0.4) or multiple tissues cluster tightly, treat the prediction with caution and consider further histopathological or molecular work‑up. We would advise to utilize the tool merely as 'advice', this is not clinicaly verified and should not be applited in clinical practifce.

## 🛠  Retraining

1. Raw expression matrices (TCGA, GTEx, metastatic) were not uploaded due to the significant size of the files, to use the data for potential retraining contact us - olandau4@gmail.com - and we will find a solution to transfer the data. 
2. Once data obtained, place the files in one folder (or set the `TCUP_DATA` environment variable to it): `BalancedTCGA_CancerTranscriptomics_withIDs.csv`, `metastatic_TOO_dataset_tpm.csv`, `data_clinical_sample.csv`, `GTEx Reads/` and `RawReadsMetastaticDataset/`.
3. install all depdencies (Script/requirements.txt)
4. Run `python "Script/TCUP v2.py"`, then `python "Script/Stand-alone MonteCarlo.py"`. The model files above are written to `TCUP v2 Results/TCUP_model`.
